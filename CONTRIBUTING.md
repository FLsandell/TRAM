# Contributing

1. Create a focused branch from the current default branch.
2. Install the project with `python -m pip install -e ".[test]"`.
3. Add or update tests for behavioral changes.
4. Run `pytest` before opening a pull request.
5. Document changes to scientific defaults or output formats in `CHANGELOG.md`.

Bug reports should include the TRAM version, complete command, Python version,
input schemas, and traceback. Do not attach sensitive or unpublished genotype
or phenotype data to public issues.
